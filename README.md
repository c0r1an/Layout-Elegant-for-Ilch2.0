# Layout-Elegant-for-Ilch2.0

This repository contains the complete `Elegant*` package for Ilch 2.0:

- `application/layouts/elegant`
- `application/modules/elegant`

Both parts belong together.

## Installation

1. Copy `application/layouts/elegant` into your Ilch installation.
2. Copy `application/modules/elegant` into your Ilch installation.
3. Install the `elegant` module in the admin area.
4. Activate the `Elegant*` layout.

## Included Features

- layout settings managed through the companion module
- homepage builder for `/index.php/elegant/index`
- dedicated Elegant* boxes
- layout-specific module view overrides
- export scripts for layout-only and GitHub bundle workflows
